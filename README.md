## Overview

ATHENA explores a scalar–disformal vacuum field model in which the vacuum is treated as a physically structured medium capable of modifying gravitational behavior across multiple scales.

The project investigates:

* Galactic rotation curves
* Gravitational lensing
* Cosmological expansion
* Emergent gravity mechanisms
* Vacuum-field dynamics

The goal is to develop a mathematically testable framework that reproduces known observations while generating falsifiable predictions.
